# 抖音广告自动跳过 - Chrome 插件

这是一个 Chrome 浏览器插件，用于在抖音网站上自动检测并跳过广告内容。

## 功能特点

- 🔍 **智能检测**: 参考油猴插件 V6.3.2 核心算法
- 🎯 **精确识别**: 收缩检测区域至屏幕左侧 2/3，物理隔离侧边栏干扰
- ⚡ **实时跳过**: 检测到后立即执行划走操作，带冷却机制
- 🛡️ **防误判**: 排除侧边栏元素 + 精确关键词匹配 + 尺寸限制
- 📊 **统计功能**: 记录已跳过的内容数量
- 🎨 **可配置化**: 支持单独控制每种类型的跳过开关

## 安装方法

### 方法 1: 开发者模式安装

1. 打开 Chrome 浏览器
2. 访问 `chrome://extensions/`
3. 开启右上角的"开发者模式"
4. 点击"加载已解压的扩展程序"
5. 选择本插件的根目录文件夹

### 方法 2: 打包安装

1. 按照上述步骤进入扩展管理页面
2. 点击"打包扩展程序"
3. 选择插件目录生成 .crx 文件
4. 双击安装 .crx 文件

## 使用方法

1. 访问抖音网站：https://www.douyin.com/?recommend=1
2. 插件会自动运行，检测并跳过广告
3. 点击浏览器工具栏的插件图标可以启用/禁用插件
4. 查看控制台日志可以看到广告跳过记录

## 技术实现

### 核心文件

- `manifest.json`: 插件配置文件
- `content.js`: 主要内容脚本，负责检测和跳过广告
- `background.js`: 后台服务脚本，处理扩展状态和消息传递
- `icons/`: 扩展图标文件

### 广告检测机制

1. **关键词检测**: 扫描页面文本中的广告相关词汇
2. **DOM 元素检测**: 查找带有广告标识的 DOM 元素
3. **视频标签检测**: 检查视频容器内的广告标签

### 划走动作实现

- 模拟键盘方向键下按（下一个视频）
- 同时执行页面滚动操作
- 确保平滑过渡到下一个视频

## 配置选项

在 `content.js` 中可以调整以下配置：

```javascript
const CONFIG = {
  checkInterval: 1000,        // 检测间隔（毫秒）
  swipeDelay: 500,            // 划走动作延迟（毫秒）
  adKeywords: [...],          // 广告关键词列表
  adSelectors: [...]          // 广告元素选择器
};
```

## 注意事项

- 插件仅在抖音网站 (`https://www.douyin.com/*`) 上生效
- 需要保持页面开启状态才能正常工作
- 某些广告可能需要调整检测参数以提高准确率

## 开发调试

1. 在扩展管理页面开启"开发者模式"
2. 点击插件 ID 可以查看详细信息
3. 在 `content.js` 和 `background.js` 中可以使用 `console.log` 输出调试信息
4. 右键点击扩展图标 -> "检查视图" 可以查看后台页面控制台
